# Career Managing

כלי לסטודנטיות ולסטודנטים בתחילת ה-MBA בפקולטה לניהול ע"ש קולר, אוניברסיטת תל אביב:
שאלון קצר, הגדרת שתי מטרות קריירה לתקופת הלימודים ובחירת פעילויות בפקולטה שיעזרו לממש אותן.

## הרצה מקומית

```bash
npm install
npm run dev
```

## פקודות

- `npm run dev` – שרת פיתוח מקומי
- `npm test` – בדיקות (Vitest)
- `npm run build` – בנייה לפרודקשן
- `npm run lint` – בדיקת קוד (oxlint)
